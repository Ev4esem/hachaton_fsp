# Design — Mochi AI

Locked design system (бренд-гайд). Future Hallmark runs read this file first; pages defer
to it. Amend intentionally — the file is the rule. Источник: логотип панды в наушниках.

## Идея бренда
Панда в наушниках с неоновой звуковой волной: «слушает, что ты сказал, и монтирует за тебя». Волна на наушнике связывает логотип с главным делом продукта: речь → субтитры → нарезка. Тон: дружелюбный, чуть дерзкий, ночная студия, не «техно-стартап». Название Mochi остаётся (чёрно-белая панда-моти).

## System
- Genre · atmospheric (тёмный интерфейс, как у видеоредакторов) с playful-маскотом
- Macrostructure · выбирается под каждую страницу; разные страницы делят одну систему
- Theme · custom (vibe: "ночная студия, панда, неоновая волна")
- Axes · dark (L < 40%) / display-heavy rounded-sans / warm accent (orange ~65°) + cool signal (cyan ~200°)

## Provenance
- Source mode · image (user-attached logo concept), user-owned
- Date · 2026-10-04
- Confidence · цвета оценены по пикселям изображения и округлены; шрифты подобраны по характеру, не извлечены. Перед финалом сверить с векторным логотипом (SVG).

## Логотип
- **Знак:** голова панды в профиль, влево, наушники закрывают ухо. На правом амбушюре: оранжевая кнопка питания и циановая линия пульса/звука. Оранжевое свечение за наушником. Жирный тёмный контур.
- **Варианты:** (1) знак + слово «Mochi» (слово набирается Display-шрифтом, вес 700, без «AI» мелким индексом); (2) только знак; (3) иконка приложения: знак на скруглённой плитке `--color-paper-sunken`.
- **Фон:** основной — тёмный слейт `--color-paper`. На светлом фоне обязательна плитка под знаком (иначе чёрные части сливаются).
- **Охранное поле:** не меньше высоты уха панды со всех сторон. Минимальный размер знака: 24 px в UI, 16 px в favicon (там убрать свечение и упростить волну до одной линии).
- **Нельзя:** менять цвет волны и кнопки, растягивать, ставить свечение на светлый фон, добавлять второй маскот, обводить знак градиентом.
- **Нужно сделать:** векторный SVG знака; вариант одной краской (белый и чёрный); favicon 16/32; упрощённая волна для малых размеров.

## Маскот
Панда живёт в состояниях продукта; везде тот же знак, меняется поза и волна.
- Пустой дашборд: панда машет, волна ровная.
- Обработка: волна пульсирует (одна анимация, `transform`/`opacity`).
- Ошибка: волна пунктиром, панда с наклоном головы, текст без вины пользователя.
- Готово: волна вспыхивает один раз.
Не ставить маскота в редактор и таймлайн: там работа, не декор.

## Tokens (canonical · `tokens.css` is the source of truth)
```css
:root {
  /* Поверхности: тёмный слейт из логотипа */
  --color-paper:        oklch(0.37 0.025 243);  /* фон лендинга, как в логотипе  ~#2d3741 */
  --color-paper-2:      oklch(0.44 0.025 240);  /* карточки, приподнятое         ~#45515d */
  --color-paper-sunken: oklch(0.24 0.020 245);  /* редактор, таймлайн, плитка     ~#17212a */
  --color-ink:          oklch(0.99 0.003 180);  /* основной текст, белая панда */
  --color-ink-2:        oklch(0.82 0.015 235);  /* вторичный текст */
  --color-ink-3:        oklch(0.72 0.020 235);  /* подписи, таймкоды */
  --color-rule:         oklch(0.50 0.025 240);  /* линии, границы */

  /* Акценты из логотипа */
  --color-accent:       oklch(0.77 0.150 65);   /* оранж: главные кнопки, кнопка питания */
  --color-accent-ink:   oklch(0.24 0.020 245);  /* текст на оранже */
  --color-signal:       oklch(0.85 0.110 200);  /* циан: волна, прогресс, активный клип */
  --color-focus:        oklch(0.85 0.110 200);  /* кольцо фокуса, показывать мгновенно */

  /* Состояния */
  --color-success:      oklch(0.80 0.140 160);
  --color-error:        oklch(0.72 0.170 25);

  --font-display: "Rubik", "Golos Text", system-ui, sans-serif;
  --font-body:    "Golos Text", system-ui, sans-serif;

  /* 4-pt spacing scale, named: --space-3xs … --space-4xl. See tokens.css.   */
  /* Type scale, 1.25 (major-third) ratio: --text-xs … --text-display.       */

  --ease-out: cubic-bezier(0.16, 1, 0.3, 1);
  --dur-fast: 180ms;  --dur-base: 240ms;  --dur-slow: 320ms;

  --radius-card: 20px;  --radius-pill: 999px;  --radius-input: 12px;
}
```
Правила цвета: оранж только на 1–2 главных действиях на экране; циан только для звука, прогресса и активного клипа; свечение (glow) допустимо только у волны и кольца фокуса, не у карточек и текста. Никаких фиолетовых градиентов. Светлая версия лендинга (кремовая бумага `oklch(0.97 0.01 85)` + тёмный слейт как текст) допустима как `## Variants`, пока не добавлена.

## Типографика
Решение владельца: никаких «типичных AI-шрифтов», никакого мелкого моно-текста и подписей капсом.
- Display · Rubik 700–800, roman (без курсива): мягкие скруглённые углы, плотный, в характере панды и в духе шортсов.
- Body · Golos Text 400–600, кириллица родная.
- Моно-шрифт не используем. Таймкоды и счётчики: Golos Text с `font-variant-numeric: tabular-nums`.
- Минимальный размер текста 15 px (`--text-xs`), основной 18 px. Подписи капсом с разрядкой не использовать.
- Проверить рендер кириллицы при подключении (Google Fonts, `subset=cyrillic`).
- Длина заголовка героя ≤ 7 слов, ≤ 50 знаков.

## Субтитры в превью стилей (сначала на тёмных кадрах)
Пресеты показывают реальный вид субтитров на кадрах; шрифты субтитров отдельные от интерфейса: жирный гротеск с кириллицей (Rubik 800 / Montserrat 800), активное слово подсвечено `--color-accent` или `--color-signal`, контур тёмный. Названия пресетов придумываем позже; метрики «как у блогера» не выдумываем.

## CTA voice
- Primary · заливка `--color-accent`, текст `--color-accent-ink`, радиус `--radius-pill`, высота 48 px, без обводки.
- Secondary · контур `--color-rule`, текст `--color-ink`, тот же радиус.
- Кнопка в одну строку всегда, не переносится.
- Тексты (RU): «Создать ролик», «Загрузить видео», «Показать стиль», «Скачать». Не «Начните сегодня», не «Революционный».

## Голос
Коротко, по-дружески, на «ты» или «вы» (решить один раз: сейчас предлагаю «ты»), с лёгким юмором. Без слов «нейросеть творит чудеса», «инновационный», «AI-монтаж». Ошибки по схеме: что случилось, что делать дальше.
Примеры: «Закинь видео, остальное на панде.» · «Не то слово? Поправь в редакторе или скажи панде.» · «Ролик готов. Проверь и скачивай.»

## Motion stance
- Тихо: 1–2 приёма на страницу (пульс волны на обработке, появление карточек).
- Только `transform` и `opacity`, три именованные кривые, никакого bounce.
- Reduced-motion fallback · ≤150 ms opacity crossfade.

## Применение по экранам
- Лендинг: тёмный `--color-paper`, панда крупно, волна как визуальный мотив разделителей.
- Мастер: светлые на тёмном карточки стилей, превью кадров с реальными субтитрами.
- Обработка: волна как индикатор прогресса по этапам.
- Редактор: `--color-paper-sunken`, таймлайн с циановым активным клипом, чат с ИИ справа.
- Тарифы: оранжевая рамка у рекомендуемого тарифа, цены-заглушки без выдуманных метрик.

## Notes (чего не переносить в дизайн)
- Не рисовать фейковые окна браузера и телефонов вокруг скриншотов продукта.
- Не использовать курсив в заголовках и «подчёркнутое» слово в заголовке.
- Не добавлять выдуманные цифры («50 000 блогеров», «×10 быстрее»), логотипы клиентов и отзывы, пока их нет.
- Не размывать оранжевое свечение на весь фон и не делать неоновые карточки.
- Не использовать тройную сетку «hero → 3 фичи → CTA → футер» как скелет лендинга.
